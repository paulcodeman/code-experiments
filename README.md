# code-experiments

Эксперименты с языками программирования, интерпретаторами, лексерами и Python-байткодом.
Семь отдельных проектов собраны в одном репозитории с сохранением исходных файлов и истории.

| Каталог | Назначение | Статус и ограничения |
| --- | --- | --- |
| [binaryscript](binaryscript/) | Экспериментальная виртуальная машина, компилятор на PHP и исполнение в JavaScript. | `compiler/index.php` обращается к закрытым полям `ip` и `data` класса `Binary` из `compiler/binary.php`. Компилятор требует доработки. Заявления об ОС и платформах в исходном README описывают замысел, а не проверенную совместимость. |
| [pythonjs](pythonjs/) | Эксперименты с исполнением старого Python-байткода в JavaScript и вспомогательные PHP/Python-скрипты. | В `js.php` целочисленное деление ошибочно реализовано через логарифмы; часть обработчиков обращается к отсутствующему `func`. Интерпретатор неполный; совместимость с современным Python не подтверждена. |
| [python-code-display](python-code-display/) | Скрипт `translate.py` для представления Python-кода в виде структуры байткода или JSON. | Некоторые константы могут не сериализоваться в JSON. Обработка вложенного кода, пропуск инструкций и удаление инструкций при импорте могут давать некорректный результат. Формат байткода зависит от версии Python. |
| [brainlet](brainlet/) | Минималистичный язык и интерпретатор на JavaScript с конечным автоматом. | В `Brainlet.js` выражение `Array(100).fill([0, 0])` заполняет память ссылками на один общий массив. Изменения ячеек могут влиять друг на друга. |
| [brainfuck](brainfuck/) | Экспериментальные реализации интерпретатора Brainfuck на C--, C, JavaScript и PHP. | В `bf.js` инструкция `[` не пропускает тело цикла при нулевой ячейке. Корректность и совместимость остальных реализаций не проверены. |
| [lisp](lisp/) | Эксперименты с интерпретатором Lisp на C--, JavaScript и PHP, включая Lisp внутри HTML. | В каталоге есть разные версии и старые реализации. Это исследовательский код без подтверждённой полноты языка, совместимости или стабильного API. |
| [lexer](lexer/) | PHP-лексер, пример входного текста и демонстрационная страница. | Перенесена PHP-версия. Демонстрация и совместимость с текущими версиями PHP не проверены; расширение на другие языки не заявлено как готовое. |

## Использование

Это экспериментальные реализации для изучения исходников и дальнейшей доработки.
Они не заявлены как готовые библиотеки или стабильные инструменты.
Исходные инструкции находятся в README соответствующих каталогов; их требования к версиям и примеры не проверялись при переносе.
Код при объединении не исправлялся и не запускался.

В `pythonjs/` сохранены ранее опубликованные `python.exe` (97 944 байта) и
`python36.dll` (3 303 064 байта). Они перенесены как обычные Git-объекты без Git LFS,
изменения байтов или запуска. Наличие файлов не подтверждает их безопасность,
происхождение, права на распространение или совместимость. Для дальнейших
экспериментов используйте отдельно установленный интерпретатор из доверенного источника.

## История

Перенос выполнен 14 ноября 2026 года через `git subtree add` без `--squash`.
Все 85 исходных коммитов доступны из `main` с прежними SHA, авторами, коммитерами,
датами, сообщениями и деревьями. В старых коммитах файлы остаются в исходных путях;
подпапки появляются в новых коммитах объединения. История не переписывалась.
Для просмотра исходной истории используйте теги `source/<каталог>/<исходная-ветка>`: `main` для Brainlet и `master` для остальных проектов.
Подробности и команды проверки — в [MIGRATION.md](MIGRATION.md).

Источники второй группы остаются публичными и не изменены при переносе:
[Brainlet](https://github.com/paulcodeman/Brainlet),
[brainfuck](https://github.com/paulcodeman/brainfuck),
[lisp](https://github.com/paulcodeman/lisp),
[Lexer](https://github.com/paulcodeman/Lexer).
Исходные репозитории первой группы (BinaryScript, pythonjs, python-code-display)
после проверки первого переноса были удалены по отдельному одобрению владельца.
Их каталоги, исходные коммиты и теги полностью сохранены здесь.

## Лицензии

Отдельные файлы лицензий в семи исходных репозиториях на момент переноса не обнаружены.
Все исходные файлы и имеющиеся уведомления сохранены без изменений.
Общая лицензия не добавлялась; перенос не предоставляет новых прав на код
или включённые бинарники. Перед повторным использованием необходимо уточнить условия.
